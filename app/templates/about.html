Research Architecture & Base Paper Comparison

Implementation and enhancement of the IEEE conference publication: "Enhancing Phishing Detection using Machine Learning Algorithms" (IEEE Xplore ID: 11005375).

Comparative Analysis: Base Paper vs. Enhanced Proposed System

Dimension Base Paper Paradigm PhishGuard Enhanced System
Feature Extraction Static CSV dataset requiring manual 48-feature entry. 100% Automated Live Extraction from user-entered URL.
Web Analysis Scope Pre-compiled offline feature tables only. Hybrid Pipeline: Lexical URL + Domain DNS + Passive HTML DOM.
Explainability Black-box classification outputs without rationale. SHAP & LIME XAI translated into natural human-readable bullets.
Adversarial Stability No perturbation or robustness testing. Controlled Robustness Suite with 5 mutation operators.
Risk Representation Binary 0/1 output without calibration. 0-100 Calibrated Risk Score with confidence grading.
Feedback Loop Static trained weights; no feedback collection. Verified Feedback Registry & Retraining Pipeline with guardrails.
Security Safeguards Unaddressed. SSRF Prevention, timeout limits, passive scraping protections.

Multi-Tier Enhanced Architecture

1. Feature Engineering
26 URL structural features, 6 Domain indicators, 16 HTML/DOM elements, and 6 benchmark Rule-Threshold derivations.
2. Model Optimization
Ensemble learning evaluated across Random Forest, XGBoost, Decision Tree, Logistic Regression, KNN, and SVM.
3. Explainable AI (XAI)
Local feature attribution via Shapley values mapped to intuitive security explanations for end users and analysts.
4. Retraining Safety
Automated regression testing prevents performance degradation before deploying retrained model candidates.
Research Disclaimer: This system is developed as an academic research prototype. Machine learning classifications reflect statistical correlations in feature distributions and should be used in conjunction with defense-in-depth cybersecurity controls.
